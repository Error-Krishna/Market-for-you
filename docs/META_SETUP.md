# Market Aura 4U — Meta (Instagram & Facebook) Setup Guide

This guide details the complete configuration required in the [Meta for Developers Portal](https://developers.facebook.com) to enable Meta Unified Login, Instagram Graph API publishing, and Facebook Pages integration for Market Aura 4U.

---

## 1. Authoritative Callback URL Specification

> [!CRITICAL]
> Meta enforces strict exact-match redirect URI validation. Any trailing slash, missing path segment, or scheme mismatch (`http` vs `https`) causes an immediate `OAuthException: redirect_uri_mismatch` error.

The following table reflects the exact production routes registered in `src/routes/v1/social/socialRouter.js`:

| Platform | Mode | Authoritative Callback URI | Source Route | Registered Express Path |
|---|---|---|---|---|
| **Instagram** | **Production** | `https://<market-aura-api>.onrender.com/api/v1/auth/social/instagram/callback` | `socialRouter.js` (L38) | `/api/v1/auth/social/instagram/callback` |
| **Instagram** (Alias) | **Production** | `https://<market-aura-api>.onrender.com/api/v1/auth/instagram/callback` | `socialRouter.js` (L40) | `/api/v1/auth/instagram/callback` |
| **Instagram** | **Local Dev** | `http://localhost:8000/api/v1/auth/social/instagram/callback` | `socialRouter.js` | `/api/v1/auth/social/instagram/callback` |
| **Facebook** | **Production** | `https://<market-aura-api>.onrender.com/api/v1/auth/social/facebook/callback` | `socialRouter.js` (L43) | `/api/v1/auth/social/facebook/callback` |
| **Facebook** | **Local Dev** | `http://localhost:8000/api/v1/auth/social/facebook/callback` | `socialRouter.js` | `/api/v1/auth/social/facebook/callback` |

> [!NOTE]
> The default OAuth redirection URI generated by the application's `getRedirectUri('instagram', req)` helper is the canonical path:
> `${PUBLIC_BACKEND_URL}/api/v1/auth/social/instagram/callback`.
> If you provide an explicit override via `INSTAGRAM_REDIRECT_URI` or `FACEBOOK_REDIRECT_URI`, the application uses that explicit string instead. Both canonical and alias paths exist in Express for complete backward compatibility.

## 2. Meta for Developers Portal Setup

### Step 1: Create or Access Your Meta App
1. Go to [developers.facebook.com](https://developers.facebook.com) and log in.
2. Click **My Apps** -> **Create App**.
3. Select **Business** as the app use case/type.
4. Name your application (e.g. `Market Aura 4U Production`).
5. Link it to your Meta Business Account.

### Step 2: Add Required Products
In the Meta App Dashboard, add the following products:
1. **Facebook Login for Business** (or Facebook Login)
2. **Instagram Graph API**

### Step 3: Configure Valid OAuth Redirect URIs
1. In the left sidebar, navigate to **Facebook Login** -> **Settings**.
2. Scroll to **Client OAuth Settings**.
3. Enable **Client OAuth Login** and **Web OAuth Login**.
4. In the **Valid OAuth Redirect URIs** field, enter both the production and development callbacks:
   ```text
   https://<market-aura-api>.onrender.com/api/v1/auth/social/instagram/callback
   https://<market-aura-api>.onrender.com/api/v1/auth/instagram/callback
   https://<market-aura-api>.onrender.com/api/v1/auth/social/facebook/callback
   http://localhost:8000/api/v1/auth/social/instagram/callback
   http://localhost:8000/api/v1/auth/social/facebook/callback
   ```
5. Click **Save Changes** at the bottom of the page.

### Step 4: Configure Meta Unified Login (`META_UNIFIED_CONFIG_ID`)
Market Aura 4U supports Meta's Unified Configuration flow for seamless Facebook and Instagram permissions:
1. Under **Facebook Login for Business** -> **Configurations**, create or locate your Configuration ID.
2. Copy the numeric Configuration ID (e.g. `1128283246795449`).
3. Set this value as `META_UNIFIED_CONFIG_ID` in your backend environment variables.

### Step 5: Required API Permissions
For full social media management and Instagram/Facebook publishing, request:
- `instagram_basic`: Reads basic Instagram account metadata.
- `instagram_content_publish`: Grants permission to publish photo and video containers to Instagram Professional accounts.
- `pages_show_list`: Discovers Facebook Pages connected to the user's account.
- `pages_read_engagement`: Reads page metrics and account status.
- `pages_manage_posts`: Publishes posts directly to managed Facebook Pages.
- `public_profile`: Standard user identity validation.

## 3. Development Mode vs. Live Production Mode

### Development Mode (Initial Testing)
- While the Meta App is in **Development Mode**, only users explicitly added to the app's **Roles** (as Administrator, Developer, or Tester) can authenticate and connect their Instagram/Facebook accounts.
- During testing, add your test Instagram Professional and Facebook accounts to **Roles** -> **Roles** in the Meta dashboard.
- Instagram accounts MUST be configured as **Instagram Business** or **Instagram Creator** accounts linked to a Facebook Page. Personal Instagram profiles are not supported by the Meta Graph API.

### Live Mode (Commercial Production)
- Before public end-users can connect their personal business accounts, Meta requires:
  1. Completion of **App Review** for the requested permissions (`instagram_content_publish`, `pages_manage_posts`).
  2. Completion of **Business Verification** (submitting company registration documents).
  3. A published Privacy Policy URL (`https://<market-aura-project>.vercel.app/privacy`) and Data Deletion Callback URL (`https://<market-aura-api>.onrender.com/api/v1/auth/social/data-deletion`).
  4. Flipping the top toggle from **In Development** to **Live**.

## 4. Backend Environment Variables Mapping

Add the following to your Render Backend environment:

```env
PUBLIC_BACKEND_URL=https://<market-aura-api>.onrender.com
FRONTEND_URL=https://<market-aura-project>.vercel.app

# Meta App Credentials
FACEBOOK_APP_ID=<your-meta-app-id>
FACEBOOK_APP_SECRET=<your-meta-app-secret>
INSTAGRAM_APP_ID=<your-meta-app-id>
INSTAGRAM_APP_SECRET=<your-meta-app-secret>

# Meta Unified Configuration
META_UNIFIED_CONFIG_ID=1128283246795449

# Optional explicit redirects (defaults to canonical paths when unset)
FACEBOOK_REDIRECT_URI=https://<market-aura-api>.onrender.com/api/v1/auth/social/facebook/callback
INSTAGRAM_REDIRECT_URI=https://<market-aura-api>.onrender.com/api/v1/auth/social/instagram/callback
```
